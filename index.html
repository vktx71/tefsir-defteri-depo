Tefsir Defteri

Kur'an-i Kerim tefsirlerini cesitli kaynaklardan indirip duzenleyen ve EPUB, PDF veya HTML e-kitap olarak disa aktaran masaustu uygulamasi.

Kurulum

Depoyu ekleyin:

flatpak remote-add --if-not-exists tefsir-defteri https://vktx71.github.io/tefsir-defteri-depo/tefsir-defteri.flatpakrepo

Uygulamayi kurun:

flatpak install tefsir-defteri io.github.vktx71.TefsirDefteri

Calistirin:

flatpak run io.github.vktx71.TefsirDefteri

Guncelleme

flatpak update io.github.vktx71.TefsirDefteri

Kaldirma

flatpak uninstall io.github.vktx71.TefsirDefteri
flatpak remote-delete tefsir-defteri
